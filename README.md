# GPT Bot

Телеграм-бот, который использует официальный [GigaChat API](https://developers.sber.ru/docs/ru/gigachat/overview) для генерации раскадровок и создаёт минутные видео на основе пользовательского запроса.

## Возможности
- Команда `/video <описание>` генерирует раскадровку из 8–12 сцен с помощью GigaChat.
- На основе сцен создаётся ролик длительностью 60 секунд (по умолчанию).
- Каждый ролик отправляется пользователю и удаляется из временной директории.

## Подготовка окружения
1. Установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Получите бесплатный доступ к GigaChat API:
   - создайте проект GigaChat API в [личном кабинете](https://developers.sber.ru/studio);
   - в разделе «Настройки API» нажмите «Получить ключ» и сохраните Authorization Key;
   - скачайте корневой сертификат Минцифры на [Госуслугах](https://www.gosuslugi.ru/crt).
3. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
   Заполните `TELEGRAM_BOT_TOKEN`, `GIGACHAT_AUTH_KEY` и путь к сертификату в `GIGACHAT_CA_BUNDLE_FILE`.

## Запуск
```bash
python -m gpt_bot.bot
```

Бот начнёт опрашивать Telegram и отвечать на команду `/video`.

## Примечания
- Физлицам доступен бесплатный объём токенов на 12 месяцев, для модели `GigaChat` (Lite) это 250 млн. Актуальные условия указаны в [тарифах](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs).
- Текст запроса передаётся в GigaChat API, поэтому не вводите личные данные.
- Проверку TLS отключать не нужно: для соединения используется сертификат Минцифры.
- Один пользователь может создавать одно видео за раз, а общее число рендеров ограничено `MAX_PARALLEL_RENDERS`.
- Генерация видео занимает продолжительное время, поэтому операция выполняется в отдельном потоке, чтобы не блокировать обработку апдейтов.
