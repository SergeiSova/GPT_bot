# GPT Bot

Телеграм-бот, который использует бесплатную модель GLM-4.7-Flash через [официальный API Z.ai](https://docs.z.ai/guides/overview/quick-start) для генерации раскадровок и создаёт минутные видео на основе пользовательского запроса.

## Возможности
- Команда `/video <описание>` генерирует раскадровку из 8–12 сцен с помощью GLM-4.7-Flash.
- На основе сцен создаётся ролик длительностью 60 секунд (по умолчанию).
- Каждый ролик отправляется пользователю и удаляется из временной директории.

## Подготовка окружения
1. Установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Получите бесплатный ключ Z.ai:
   - зарегистрируйтесь на [платформе Z.ai](https://z.ai/model-api);
   - создайте Standard API Key на [странице ключей](https://z.ai/manage-apikey/apikey-list).
3. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
   Заполните `TELEGRAM_BOT_TOKEN` и `ZAI_API_KEY`.

## Запуск
```bash
python -m gpt_bot.bot
```

Бот начнёт опрашивать Telegram и отвечать на команду `/video`.

## Примечания
- GLM-4.7-Flash указана бесплатной в [тарифах Z.ai](https://docs.z.ai/guides/overview/pricing). Лимиты запросов там не опубликованы, поэтому при нагрузке API может временно отвечать ошибкой.
- Текст запроса передаётся в Z.ai, поэтому не вводите личные данные.
- Закреплённые зависимости рассчитаны на Python 3.10–3.12.
- Один пользователь может создавать одно видео за раз, а общее число рендеров ограничено `MAX_PARALLEL_RENDERS`.
- Генерация видео занимает продолжительное время, поэтому операция выполняется в отдельном потоке, чтобы не блокировать обработку апдейтов.
